# Nikobus NG has moved

Nikobus NG, the second, experimental Nikobus integration (domain
`nikobus_ng`), was written in this folder up to version 0.9.1. It now has
a repository of its own, with its history:

**https://github.com/fdebrus/Nikobus_NG**

It installs from there through HACS, as a custom repository. The Nikobus
integration in this repository is not affected: it stays, and stays
maintained.

The review of the Nikobus integration that Nikobus NG's design started
from is in [documentation/nikobus-ng-review.md](../documentation/nikobus-ng-review.md).
